# Limits 1.0.0

Limits 1.0.0 turns the prototype into a complete native macOS app for seeing and switching Codex CLI and Claude Code account limits.

- Native SwiftUI account window, menu bar panel, Settings scene, and WidgetKit extension.
- Stable account identity and safe migration to the v2 state schema.
- Transactional Codex and Claude switching with identity validation and rollback.
- Explicit freshness for tray and widget values, with stale percentages suppressed instead of presented as current.
- Launch at Login through macOS Service Management.
- Signed Sparkle updates from a public appcast.
- Apple-silicon Xcode archive with Developer ID signing, hardened runtime, notarization, and stapling.
