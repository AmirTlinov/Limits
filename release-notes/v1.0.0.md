# Limits 1.0.0

Limits 1.0.0 is the first stable native macOS release for seeing, understanding, and switching Codex and Claude Code account limits.

- A new Codex Overview shows the nearest weekly-limit risk, tokens, credits, current API-price equivalent, subscription economics, model mix, and daily trend.
- Automatic forecasts explain whether each weekly limit will run out before reset, last until reset, still needs pace observations, or has stale evidence.
- Official `account/usage/read` totals reconcile with numeric local Codex events; conversation text and project contents are never stored by Limits.
- Versioned official Codex and API rate cards keep historical calculations reproducible and show one calm in-app notice when a confirmed price changes.
- Native SwiftUI account window, menu bar panel, Settings scene, and WidgetKit extension share the same immutable analytics snapshot.
- A single v4 accounts repository keeps identities, subscription state, and credential references; `CodexUsageRepository` owns history in system SQLite.
- Atomic revisioned state, copy-on-write Keychain credentials, one-way migration with backup, 90-day raw-event retention, and cascade deletion.
- Serialized Codex and Claude sessions with identity validation, rotation capture, stale-operation rejection, and conflict-aware rollback.
- Claude stays out of the window, filter, tray, Settings, and widget until a saved account or live stable signed-in identity exists.
- One 15-minute freshness contract for the window, tray, and widget, with stale percentages suppressed instead of presented as current.
- Large widgets add the nearest weekly risk, weekly tokens, and credits; the tray adds only the current account forecast.
- Statistics can be cleared or explicitly reimported from Settings without touching saved accounts or credentials.
- Launch at Login through macOS Service Management.
- Hostless unit tests, isolated UI/runtime tests, and signed Sparkle updates from immutable public GitHub Pages URLs.
- Apple-silicon Xcode archive with Developer ID signing, hardened runtime, notarization, and stapling.
