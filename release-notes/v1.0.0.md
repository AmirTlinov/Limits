# Limits 1.0.0

Limits 1.0.0 turns the prototype into a complete native macOS app for seeing and switching Codex CLI and Claude Code account limits.

- Native SwiftUI account window, menu bar panel, Settings scene, and WidgetKit extension.
- A single v3 accounts repository with atomic revisioned state, copy-on-write Keychain credentials, and one-way migration with backup.
- Serialized Codex and Claude sessions with identity validation, rotation capture, stale-operation rejection, and conflict-aware rollback.
- Claude stays out of the window, filter, tray, Settings, and widget until a saved account or live stable signed-in identity exists.
- One 15-minute freshness contract for the window, tray, and widget, with stale percentages suppressed instead of presented as current.
- Launch at Login through macOS Service Management.
- Hostless unit tests, isolated UI/runtime tests, and signed Sparkle updates from immutable public GitHub Pages URLs.
- Apple-silicon Xcode archive with Developer ID signing, hardened runtime, notarization, and stapling.
