# Limits 1.0.1

Limits now gives Codex CLI and Claude Code accounts one native place to answer the useful question: which account is closest to its limit, and will it last until reset?

## What is included

- A yearly Codex usage overview with token activity, totals, model mix, trends, projects, and tasks.
- Reset-aware forecasts that distinguish a likely shortfall, enough capacity, stale evidence, and a pace that is still being learned.
- Transactional Codex and Claude Code account switching with identity validation and automatic restoration after a failed replacement.
- Native app, menu bar, and WidgetKit surfaces driven by the same account and freshness rules.
- Local usage history in SQLite, credentials in macOS Keychain, and a sandboxed widget snapshot that contains no credentials or work labels.
- A signed Sparkle update channel and a release gate that requires Developer ID signing, Apple notarization, a stapled ticket, public checksums, and a verified upgrade from the previous signed release.

## Requirements

Limits 1.0.1 requires an Apple-silicon Mac running macOS 26 or newer. The release archive is distributed with a SHA-256 checksum.
